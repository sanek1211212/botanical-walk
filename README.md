# Лесная прогулка вдвоём

Познавательный маршрут для двоих по девяти деревьям ботанического сада. На каждой остановке есть факт о дереве и короткое задание для совместного обсуждения.

## Карта маршрута

Интерактивная схема размещена в `index.html`. Номера на карте соответствуют порядку остановок; нажмите доступную метку, чтобы открыть описание дерева. После отметки «Мы тут» состояние точки обновится и на карте, и в списке маршрута. Для подробного просмотра увеличьте схему или откройте оригинальный PDF.

Файлы карты: `assets/botanical-garden-map.png` (просмотр в приложении) и `assets/botanical-garden-map.pdf` (оригинальная схема).

## QR-код для презентации

QR-код ведёт на опубликованную прогулку:

- `assets/botanical-walk-qr.png` — PNG 2400 × 2400 пикселей, 300 DPI, удобно вставить в презентацию.
- `assets/botanical-walk-qr.svg` — векторный SVG для масштабирования без потери качества.

## Запуск

Откройте `index.html` в браузере. Отметки маршрута сохраняются в локальном хранилище браузера на текущем устройстве.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** репозитория.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. После публикации сайт будет доступен по адресу `https://sanek1211212.github.io/botanical-walk/`.
